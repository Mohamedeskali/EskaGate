API Test Console — Windows و Ubuntu
===================================

1) انسخ جميع ملفات هذا المجلد إلى نفس المجلد الذي يحتوي عليه
   (أو في أي مجلد آخر، لكن حافظ على نفس الملفات مع بعضها).

2) لتشغيل الـ dashboard الآن:
   - اضغط نقرة مزدوجة على "Run API Dashboard.bat"
   - سيُشغّل السيرفر ويفتح المتصفح تلقائيا على http://127.0.0.1:8000
   - لا تغلق نافذة الطرفية (CMD) لأن السيرفر يحتاجها للبقاء شغالا.
   - لإيقاف السيرفر: اضغط Ctrl+C في النافذة أو أغلقها.

3) لإنشاء اختصار على سطح المكتب:
   - اضغط نقرة مزدوجة على "create_shortcut.vbs"
   - سيظهر إشعار بنجاح الإنشاء.
   - سيظهر أيقونة باسم "API Test Console" على سطح المكتب
     عند الضغط عليها سيفتح السيرفر والمتصفح تلقائيا.

4) إذا أردت تغيير المنفذ (port):
   - عدّل رقم 8000 في ملف "Run API Dashboard.bat" إلى أي رقم آخر
     مثل 8080، ثم عدّل نفس الرقم في "create_shortcut.vbs"
     إن أردت تغيير عنوان المتصفح.

تشغيل Ubuntu / Linux
--------------------

1) تأكد أن Python 3 موجود:
   python3 --version
   إذا لم يكن موجوداً في Ubuntu:
   sudo apt install python3

2) من داخل هذا المجلد، أعطِ ملف التشغيل صلاحية التنفيذ (مرة واحدة فقط):
   chmod +x run-api-dashboard.sh

3) شغّل اللوحة:
   ./run-api-dashboard.sh

   سيفتح المتصفح تلقائياً على http://127.0.0.1:8000
   ولتشغيلها على منفذ آخر، مثلاً 8080:
   ./run-api-dashboard.sh 8080

4) لإيقاف السيرفر: اضغط Ctrl+C في الطرفية.

لا توجد مكتبات Python خارجية مطلوبة؛ المشروع يستخدم مكتبات Python القياسية فقط.

ملاحظة حول اكتشاف النماذج
--------------------------

البرنامج يجرب روابط /models و /v1/models الشائعة، ثم يرسل رسالة اختبار
قصيرة إلى كل موديل تم العثور عليه. إذا كانت خدمة الـ API تمنع عرض قائمة
النماذج لهذا المفتاح، لا يمكن استنتاج أسماء النماذج من المفتاح وحده؛ أدخل
أسماء النماذج المسموح بها في حقل "موديلات يدوية" ليتم اختبارها مباشرة.

AI Gateway محلي (تبويبات: المزودين، Gateway، الوكلاء)
-----------------------------------------------------

1) المزودين: زيد مزود (الاسم + Base URL + الصيغة OpenAI ولا Anthropic)، ومن بعد
   لصق مفتاح ولا بزاف (واحد فكل سطر) وضغط "اختبر المفاتيح". الموديلات كيتجابو تلقائياً.

2) Gateway: البرنامج كيولد مفتاح محلي (sk-local-...). الوكلاء كيستعملوه على:
     OpenAI     http://127.0.0.1:8000/v1        (/chat/completions)
     Anthropic  http://127.0.0.1:8000           (/v1/messages)
   الـ gateway كيختار مفتاح حقيقي خدام، وإلا فشل ولا وصل للحد كيدوز للي موراه.
   السجل كيبين الموديل والمزود والنتيجة فقط، بلا محتوى الرسائل.

3) الوكلاء: "تفعيل" كياخد نسخة احتياطية ويكتب الرابط والمفتاح المحلي فإعدادات
   Claude Code / opencode / Hermes. "إيقاف" كيرجع الإعدادات الأصلية.
   عاود شغّل الوكيل من بعد التفعيل، وخلي هاد البرنامج شاعل مادام الوكيل خدام بيه.

المفاتيح الحقيقية والنسخ الاحتياطية كيتحفظو فـ ~/.api-test-console (مقروءة غير ليك).

تطبيق ESKALI_API (أيقونة فقائمة التطبيقات)
------------------------------------------

1) تثبيت (مرة وحدة، ولا عاودو إلا بدلتي بلاصة المجلد):
   ./install_eskali_api.sh

2) من بعد غادي تلقى ESKALI_API فقائمة التطبيقات وعلى سطح المكتب.
   كليك عليه: كيشعل السيرفر فالخلفية (بلا طرفية) وكيحل المتصفح.
   إلا كان شاعل ديجا، كيحل غير المتصفح.

3) باش توقفو: كليك يمين على الأيقونة ← "إيقاف ESKALI_API"
   ولا: ./eskali_api_launcher.sh stop

4) السجل (log): ~/.api-test-console/eskali_api.log

5) باش تحيدو من التطبيقات: ./install_eskali_api.sh --uninstall
